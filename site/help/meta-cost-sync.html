Syncing Meta ad spend

Connect Meta under Manage → Integrations and match ad spend to campaigns by the ad-platform campaign ID.

Updated 5 October 2026

What the cost sync does

Meta Ads cost sync pulls each day's spend, impressions and clicks from Meta and folds the spend into the matching tracker campaign, so cost, profit and ROI line up without you typing daily budgets by hand. It runs on a schedule, off the tracking path, or on demand with Sync now. The spend it reads for a matched campaign and day is treated as authoritative for that day.

There are two halves: connect the platform and choose your ad accounts once under Manage → Integrations, then switch the sync on and tune it under Settings → Meta Ads cost sync.

Connect Meta under Integrations

  1. Open Manage → Integrations. The Ad platforms card lists Meta alongside placeholders for the other platforms.
  2. Press Connect on the Meta tile. The browser leaves the tracker, you authorise on Meta, and it returns to the Integrations page with a confirmation.
  3. Once connected, the tile shows Connected as … with the number of ad accounts and datasets discovered, and the expiry date of the connection.

If the tile ever reads Needs reconnect, the stored token can no longer be read or has expired — press Connect again. Disconnect removes the connection and its stored token.

Pick the ad account(s)

With Meta connected, the tile shows Ad accounts for cost sync, a multi-select fed by the accounts discovered on your connection. Select every account whose spend you want tracked and press Save accounts. This is the only place accounts are chosen; the cost-sync card in Settings shows the saved list read-only, which is why it can look empty until you choose here.

With no account selected, the sync has nothing to read. If the picker is empty, the connection exists but Meta returned no ad accounts for it — reconnect and grant access to the right business.

Turn the sync on and set its cadence

Open Settings → Meta Ads cost sync (under the ad-platform section) and switch on Keep my Meta costs up to date. Then set:

SettingWhat it controls
Test modeWork out the numbers and log them, but don't change any costs yet. On by default — nothing is written until you switch it off.
How oftenThe cadence: Hourly or Daily.
Days to look backThe backfill window, re-checked on every run. Default 7; set 0 for yesterday only. A wider window re-reads recent days, so late-published spend self-corrects.
Match campaigns byHow Meta campaigns are matched to yours: Auto — best match (recommended), Meta campaign ID, Campaign name or Tracking ID (UTM / sub-id).

The last sync time, outcome, and the matched / unmatched counts are shown next to Sync now. A failed run records its error there rather than silently doing nothing.

How spend is matched to a campaign

Every Meta insight row carries a platform campaign id and name. The sync indexes your campaigns and matches in this order:

  1. the campaign's explicit Ad-platform campaign ID column, then
  2. the campaign name (case-insensitive), then
  3. the campaign's tracking id.

Auto lets all three run in that order. Choosing one of the other values restricts matching to that single strategy, which is useful when names collide and you want the id to be the only truth.

Set the Ad-platform campaign ID

Open the campaign and find Ad-platform campaign ID on the Settings step. Its hint reads Meta Ads campaign id — used by the Meta Ads cost sync to match spend to this campaign. When a Meta connection exists, this is a picker fed by your discovered Meta campaigns; without one, you can type the id by hand. Leave it empty and the sync falls back to matching on name or tracking id, which is less reliable.

Test mode and Sync now

In Test mode the sync still makes the read-only request and computes every match, but writes no costs — the result panel shows exactly what it would have done. Use Sync now to run it on demand; the button respects test mode. Once you are happy with the matches, turn test mode off and run again to write the costs.

Spend is spread across the matched campaign's clicks for that day. If a matched campaign-day had no tracker clicks, the daily figure is still stored for the audit trail but there is nothing to allocate. Transient network failures are retried with backoff before a run is marked failed.

Test mode is on by default

A fresh setup records runs and computes matches but never changes a cost. If your campaign cost stays at zero while the sync looks healthy, check that Test mode is off and that at least one ad account is selected under Integrations.

If a cost is missing or wrong after a run, work through Cost is missing or wrong. For how costs are recorded in the first place — models, the cost parameter and per-click allocation — see Cost models and cost handling.
