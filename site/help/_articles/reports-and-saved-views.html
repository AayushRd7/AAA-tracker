Break down by any dimension

Open Performance → Reports. The report builder turns your live click stream into a drill-down table. Choose a Date range, one or more Campaigns, and an ordered set of dimensions in the Breakdown pipeline, then press Run report.

You can stack up to five dimensions. They read left to right, and clicking a value in the table expands the next level beneath it. Any of these can be a dimension:

  • Time — date, hour, ISO week
  • Objects — campaign, offer, landing page
  • Geo — country, region, city
  • Device — device type, OS, OS version, browser, language
  • Traffic — traffic source, UTM source/medium/campaign/creative, keyword, ISP, connection type
  • Identifiers — Sub ID 1 through Sub ID 10, domain, IP, user agent
  • Quality — conversion status, bot flag, proxy flag

Preset chains load in one click: SubID chain, Geo chain, Traffic chain and Funnel. The Report templates gallery loads a whole configuration — dimensions, columns and window — for common jobs such as campaign performance, offer/landing split or device breakdown.

Metrics and date basis

Columns include visits, unique visits, clicks, unique clicks, leads, conversions, rejected, cost, revenue, profit, and the derived CR %, EPC and ROI %, plus bot clicks, bot cost, fraud score average and human clicks. Pick the columns you want, sort by any of them, and use Custom metrics to add a formula over the built-in keys, for example conversions*100/clicks.

The Click date / Conversion date toggle decides which timestamp the range filters on. Click date counts a conversion on the day its click happened; conversion date counts it on the day the conversion arrived. Compare the two when a network reports late.

Saved views, presets and templates

Three different things can be saved here, and they are not interchangeable:

WhatActionWhat it stores
Saved reportSave reportDimensions, columns, custom metrics, date basis and filters — reload it from the Saved reports dropdown
Column templateSave as templateOnly which columns are visible in this table
Filter presetSave filtersOnly the filter values currently applied

Use as default pins the current columns as the workspace default for that table, so the next person opening it sees the same view.

The conversion log

Below the builder is the Conversion log — every conversion received via postback. Filter it by Status, Approval, a free-text Search (click id, external id, transaction id, visitor id) and Offer URL contains. Each row has an Edit action and a Delete action.

Edit opens a dialog where you can change Status, Approval, Payout, Revenue, External ID and Transaction ID. This is how you correct a conversion a network reported late, or with the wrong status or amount. Select rows to apply a status or approval in bulk, and use Add conversion or Import for offline sales. Remember that a later postback still updates the row: status follows the latest event and payout accumulates, so a manual edit is not necessarily final.

The read-only list of the same records lives at Logs → Conversions; editing happens here.

Exporting

Export CSV appears on the report, the click log and the conversion log, and exports exactly what the current filters select. Every cell is quoted, so values always open as plain text and separators or newlines cannot break the rows. The separate Warehouse export card writes raw click, conversion and cost datasets with a manifest for BI tools, over its own date range and with optional gzip.

Retroactive cost update

When cost is missing or wrong for a period, an admin can correct it without re-importing anything. Press Cost update and choose an optional Campaign (leave it empty for all campaigns), a From and To date, and a Cost per click. The tracker overwrites the per-click cost on every matching row, so total spend is cost × matched rows and existing costs are replaced rather than added. A cost of 0 clears costs for the window. Every change is recorded in Logs → Cost updates with who ran it and how many rows changed. See also Cost models and cost handling.

Sharing a report

Save a report, then use its Share report action to create a tokenized public link. Anyone with the link — a client or a partner — sees a clean read-only copy of that one breakdown, with no login required. Revoking the link or re-creating it invalidates the old one instantly. A saved report can also be emailed on a schedule with Email schedule.

A capped report shows short totals

A breakdown returns at most 1,000 rows. When that cap is reached the table says so, and the totals only cover the rows shown. Narrow the date range or campaigns, add a filter, or use fewer dimensions to see every row.
