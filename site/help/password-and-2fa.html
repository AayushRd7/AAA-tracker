Password, two-factor and sessions

Change your password, turn on two-factor authentication and review the sessions signed in to your account.

Updated 5 October 2026

Change your password

Open the account menu in the top bar and choose Change password. The dialog asks for three values:

  • Current password — proving it is you; the change is refused without it.
  • New password — the field label reads New password (min 6 chars). (The invitation and reset forms ask for at least 8 characters.)
  • Repeat new password — must match the new one.

Press Change and the new password is live on your next sign-in. Changing your password this way does not sign your other devices out — sessions stay valid until they expire or you revoke them. If you want devices signed out as well, use the sessions card described below, or the reset flow.

Forgot your password

On the sign-in page, follow Forgot password?. Enter your Username or email and press Email me a reset link. The tracker answers the same way whether or not the account exists, so the page cannot be used to discover which accounts are real, and it emails a link only when there is a matching account with an address. If nothing arrives, check that the account has an email on file.

The email carries a link that opens the sign-in page in a reset state, asking for a New password and a confirmation. The link is single-use and expires after 60 minutes; a fresh request spends any earlier outstanding links. A completed reset requires at least 8 characters.

What a reset does to your sessions

A password reset is a security event: setting a new password through the emailed link signs every session on the account out, including any you had open on other devices. You then sign in again with the new password. This is the difference worth remembering — Change password leaves other sessions running; a forgot-password reset ends them all.

The thing readers get wrong

People use "reset my password" when they mean "change my password", and are surprised to be logged out everywhere. Use Change password when you know the current one and want to stay signed in; use the forgot-password link when you do not, and expect to sign in again on every device.

Set up two-factor authentication

Open the account menu and choose Two-factor authentication. With 2FA off, press Set up 2FA and the dialog walks you through it:

  1. Scan the QR code with an authenticator app, or copy the secret shown beside it and enter it manually.
  2. Type the 6-digit verification code the app generates.
  3. Press Enable 2FA.

On success you are shown 10 backup codes. They are displayed only once, so save them somewhere safe now. Each backup code is a single-use, 8-character code (the alphabet avoids 0, O, 1 and I), and each works exactly once — in place of, not in addition to, a normal code.

Signing in with 2FA

After your username and password are accepted, the sign-in page asks for a code. Enter the current 6-digit authenticator code, or one of your backup codes. The authenticator code is accepted within a small ±1 time-step window, so a code from the neighbouring 30-second slot still works. If you have lost your authenticator and your backup codes, a platform operator can reset 2FA for the account so you can sign in with a password and set it up again.

Disabling 2FA

Open the same dialog; with 2FA enabled it shows the enabled state and a Disable 2FA button. Disabling requires your password, and it clears the secret and the backup codes.

View and revoke active sessions

Open Account → Users and find the Active sessions card. It lists the devices currently signed in to your account, newest first, with the device type, operating system, browser, IP, location, when each was last seen and when it started. The row for the device you are using now is tagged This device.

  • Revoke one session — press the red revoke action on any row that is not the current device. That device is signed out immediately.
  • Log out all other devices — the button above the table ends every session except the one you are using, and reports how many it revoked.
  • The current device cannot be revoked from this list — use Logout in the account menu when you want to end it.

Location comes from the proxy or CDN geo information attached to the request; where none is present the location stays blank rather than being guessed. Platform operators can additionally open another user's Devices list from the Platform users card.

If you think an account is compromised

Reset the password through the forgot-password flow — that signs every session out at once — then sign back in, turn on two-factor authentication, and review Active sessions for anything you do not recognise. Security-relevant changes such as 2FA enable, disable and resets are recorded in the audit log under Settings → Audit log.
