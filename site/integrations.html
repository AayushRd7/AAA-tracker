Affiliate networks & offers

Offers modelled the way you actually run them.

Server-side conversion APIs

Send the signal the platform needs to optimise.

Cookie limits and iOS restrictions made browser-side pixels less reliable. AAA Tracker pushes conversion events server-to-server, carrying a shared event id so the ad platform can match the event to the click and keep learning from real outcomes.

  • Server-to-server, not best-effort — fewer dropped events and a signal that survives cookie restrictions.
  • A shared event id — the strongest possible match between what the platform spent and what it earned.
  • Only the events you choose — nothing leaves the tracker unless you configured that connection deliberately.
  • Built to grow — Meta is live today; more platforms are in progress and marked coming soon.

Click API

Route a click from anywhere.

Post a click from an app, a webview or your own backend, and get the routing decision back as JSON — the same engine and the same rules, without a redirect.

  • POST a click with the parameters your product already has.
  • Get JSON back — the chosen flow, the destination, and the click id for the postback.
  • One set of rules — filters, caps, dayparting and fraud scoring all behave exactly as they do on a redirect.

Integration FAQ

Missing an integration you need?

What if my traffic source isn’t listed?

Add it in about a minute: give it a name and the macro names your platform emits. From that point it behaves exactly like a built-in source, with the same reporting columns and routing fields.

Which conversion APIs are live today?

Meta is live. TikTok, Google Ads, Snapchat, Pinterest, AppLovin and ChatGPT Ads are in progress and marked coming soon — the same connection pattern will apply as each one lands.

Does cost sync write automatically?

Only after you have seen the dry-run and approved it. You choose the accounts, and campaigns are matched on ad-platform id first, then name, then tracking id.

Is there an API for everything else?

Yes — campaigns, offers, costs and reports can be read and written through the API, and the Click API returns routing decisions as JSON for app and webview traffic.
