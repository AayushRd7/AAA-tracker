Integrations

Your traffic in, your platforms out.

A tracker is only as good as the data you feed it. AAA Tracker connects to the sources you buy on, the networks you run offers for, and the ad platforms that need your conversion signal back — so clicks, costs and conversions meet in one place instead of in a spreadsheet.

Traffic sources

Every source ships with its real macros.

Pick a source and AAA Tracker already knows its parameter names. Campaign, placement, keyword, device, creative and sub-id values arrive intact, with no hand-built query strings and no guessing which macro maps to which column. Names below are the sources we support; connecting a custom one takes about a minute.

Macros that map cleanly

Each supported source carries its own macro set, so the click you receive lands in the right columns. Placement stays placement, keyword stays keyword, and your sub-ids stay yours.

Bring your own source

Not on the list? Define a custom traffic source and enter the macro names your network or platform actually emits. It behaves like any built-in source from that point on.

Consistent reporting

Because every source speaks the same column names, reports, rules and routing conditions work the same way regardless of where the click came from.

Affiliate networks & offers

Offers modelled the way you actually run them.

A network defines your offer catalogue and the postback format it will call. AAA Tracker keeps the shape of that catalogue so an offer is more than a name and a URL.

  • Per-offer payout, so revenue lines up with the deal you signed.
  • A daily conversion cap per offer, with an overflow offer that takes the traffic once the cap is reached.
  • Conversion-type mapping, so lead, sale, trial and install are recorded as the type your network reports.
  • Status mapping, so approved, pending and rejected postbacks land in the right state instead of one generic bucket.

Server-side conversion APIs

Send the signal the platform needs to optimise.

Cookie limits and iOS restrictions made browser-side pixels less reliable. AAA Tracker pushes conversion events server-to-server, carrying a shared event id so the ad platform can match the event to the click and keep learning from real outcomes.

Meta Snapchat Coming soon TikTok Coming soon Pinterest Coming soon Google Ads Coming soon AppLovin Coming soon ChatGPT Ads Coming soon

Server-to-server, not best-effort

The conversion is sent from our servers to the platform's conversion API, not from the visitor's browser. That means fewer dropped events and a signal that survives cookie restrictions.

A shared event id

Each event carries an identifier shared between the click and the conversion, giving the platform the strongest possible match between what it spent and what it earned.

Only the events you choose

Decide which conversion types go out to which platform. Nothing leaves the tracker unless you have configured that connection deliberately.

Built to grow

Meta is live today. More platforms are in progress and marked coming soon — the same connection pattern will apply as each one lands.

Ad-platform cost sync

Real spend, not estimated spend.

Profit and ROI only mean something if cost is accurate. AAA Tracker pulls daily spend, impressions and clicks from the ad platform, per campaign, and writes them into the tracker's cost so your numbers reflect what you were actually charged.

  • Daily cost, impressions and clicks per campaign, written straight into the tracker.
  • Dry-run mode first, so you can see what would be written before a single number is applied.
  • You choose which ad accounts are connected — never all of them by default.
  • A clear campaign-matching rule: match on the ad-platform campaign id first, then the campaign name, then the tracking id.

Click API

Route a click from anywhere.

For apps, webviews and any surface that is not a browser landing page, post the click to the Click API and get the routing decision back as JSON. Same rules, same offers, same reporting.

POST a click

Send the click with its source, sub-ids and any custom parameters. The tracker records it and evaluates your routing rules as usual.

Get JSON back

The response tells you the decision — which offer, which destination — so your app can act on it immediately without parsing a redirect.

One set of rules

Because the Click API runs through the same routing engine, a rule you change affects every surface that sends you clicks.

Questions

Integration FAQ

Do I need to be technical to set these up?

No. Connections are made through a guided authorisation flow and a short set of choices about which accounts and datasets to include. Server-to-server conversion APIs and cost sync are configured for you; the Click API is there when a developer on your side wants it.

Which platforms are live today?

Meta is available now for server-side conversion events. Snapchat, TikTok, Pinterest, Google Ads, AppLovin and ChatGPT Ads are in progress and marked coming soon. Traffic-source support is broader and already includes the sources listed on this page.

Can I add a source that is not listed?

Yes. Define a custom traffic source with the macro names your platform actually emits, and it behaves like any built-in source in routing, reporting and rules.

Where are the credentials kept?

Platform credentials are configured for the deployment rather than entered per user. Tokens are encrypted at rest, and nothing is entered into a shared settings page that other accounts can read.

How does cost sync avoid wrong numbers?

You can run it in dry-run mode first to see exactly what would be written. Once you are satisfied, it writes daily spend, impressions and clicks into your tracker cost using the campaign-matching rule: campaign id, then name, then tracking id.

What if the platform changes something?

Connections are maintained against the platforms' current APIs. When a platform changes its requirements, the connection is updated so your data keeps flowing without a rebuild on your side.

Missing an integration you need?

Tell us which traffic source, network or ad platform is standing between you and clean numbers. We will tell you honestly whether it is supported today, in progress, or something we can build a custom connection for.
